# 교수님께 요청드릴 메일 (도메인 재지정)

도메인·웹호스팅 신청의 **서비스 대상이 "교원, 직원"**(매뉴얼 3p)이라, 종합정보시스템
신청서와 정보통신처 문의 모두 **교수님 계정·교수님 메일**로 진행해야 한다.

신청 도메인은 **기존 `psynr.cau.ac.kr`의 연결 대상 변경(재지정)**이다. 이 레코드는 이미
외부 Wix로 CNAME 되어 있어, 외부 호스팅 연결이 가능하다는 선례가 레코드 자체에 있다.

## 1. 어디로 보내는가

| | 내용 |
|---|---|
| **정식 신청 경로** | 종합정보시스템(`cauweb.cau.ac.kr`) > 행정 > 정보통신처 > 신청서 관리 > 도메인 신청 |
| **사전 문의 메일 수신처** | 정보통신처 **정보인프라팀** (도메인·DNS 담당) |
| **확인된 연락처** | IT콜센터 02-820-6161 / 정보인프라팀 02-820-6161·6164, `itsecurity@cau.ac.kr` |
| **주의** | 위 메일 주소는 공개 자료 기준이라 **발송 전 IT콜센터(02-820-6161)로 도메인 담당자 주소를 한 번 확인**하는 편이 확실하다. IT Help Desk(`ithelp.cau.ac.kr`)에 문의 접수도 가능하다. |

메일은 신청서를 대신하는 것이 아니라, **연결 방식과 접수 절차를 먼저 확인**하기 위한
사전 문의다. 기존 레코드 변경이라 신청서 접수 자체가 필요 없을 수도 있으므로,
회신을 받은 뒤 움직이는 순서가 안전하다.

## 2. 교수님께 드릴 메시지 (그대로 복사해서 전달)

```
교수님, 안녕하세요.

연구실 홈페이지를 새로 만들어서, 기존 연구실 도메인(psynr.cau.ac.kr)을
새 홈페이지로 연결하려고 준비 중입니다.
현재 psynr.cau.ac.kr은 예전 Wix 사이트를 가리키고 있어 접속하면 404가 뜹니다.

도메인 관련 신청은 교원·직원 계정만 가능해서, 두 가지만 부탁드리려고 합니다.

1) 점검표 양식 내려받아 전달 부탁드립니다
   - 위치: 종합정보시스템 > 행정 > 정보통신처 > 신청서 관리 > 도메인 신청
           화면 하단의 "의무 이행사항 안내"
   - 필요한 양식 두 가지
     · 홈페이지 취약점 심층점검 점검표
     · 개인정보 처리시스템 안전조치 관리실태 점검표
   - 양식만 주시면 제가 내용을 채워서 정리해 드리겠습니다.
     (홈페이지 보안 설정과 개인정보처리방침은 이미 반영해 두었습니다)

2) 정보통신처에 아래 메일 발송 부탁드립니다
   - 연결 대상 변경 요청과 접수 절차 확인 내용입니다.
   - 받는 곳: 정보통신처 정보인프라팀
     (담당자 주소는 IT콜센터 02-820-6161로 확인 부탁드립니다)

회신이 오면 신청서에 적을 내용까지 정리해서 드리겠습니다.
감사합니다.
```

## 3. 정보통신처에 보낼 메일 초안

> **받는 사람**: 정보통신처 정보인프라팀 (담당자 주소 확인 후 기재)
> **제목**: [도메인 문의] psynr.cau.ac.kr 연결 대상 변경 요청 — 적십자간호대학 정신건강간호연구실

```
안녕하십니까.
중앙대학교 적십자간호대학 정신건강간호연구실(Trauma Stress Lab) 최윤정 교수입니다.

연구실 홈페이지를 새로 구축하여, 기존 도메인 psynr.cau.ac.kr 의 연결 대상 변경을
요청드립니다.

1. 변경 요청 내용
   - 현재: psynr.cau.ac.kr → 외부 Wix 서비스(td-ccm-neg-87-45.wixdns.net)로 연결.
     해당 사이트가 종료되어 접속 시 404가 반환되고 있습니다.
   - 요청: psynr.cau.ac.kr → caupsynr.onrender.com (CNAME)
   - 새 홈페이지는 Python/Flask로 개발되어 교내 웹호스팅(ASP·PHP)에서는 운영이 어려워
     외부 클라우드(Render)에서 운영 중입니다. 현재 주소: https://caupsynr.onrender.com
   - 해당 서비스는 고정 IP를 제공하지 않고 호스트명 기준 연결(CNAME)을 사용합니다.
     현재도 외부 서비스로 CNAME 되어 있는 만큼, 같은 방식으로 대상만 변경해 주시면
     되는지 확인 부탁드립니다.
   - CNAME이 어려울 경우 현재 IP(216.24.57.7 / 216.24.57.15)로 A 레코드 등록이
     가능한지, 이후 IP가 변경될 때의 절차는 어떻게 되는지 함께 안내 부탁드립니다.
   - 종료된 외부 서비스를 가리키는 레코드가 남아 있으면 서브도메인 탈취 위험이 있어,
     조속한 변경을 요청드립니다.

2. 접수 절차 및 점검표
   - 종합정보시스템 도메인 신청서로 접수하면 되는지, 기존 레코드 변경은 별도 절차가
     있는지 안내 부탁드립니다.
   - 홈페이지 취약점 심층점검 점검표를 작성해 첨부할 예정입니다.
     연구자 전용 로그인 기능이 있어(공개 회원가입은 없습니다) 개인정보 처리시스템
     안전조치 관리실태 점검표도 함께 첨부하려 하는데, 대상 여부 확인 부탁드립니다.
   - 현재 사이트에는 HTTPS 전용 리다이렉트, HSTS 및 CSP 등 보안 헤더, CSRF 토큰 검증,
     비밀번호 해시 저장(PBKDF2-SHA256), 로그인 시도 횟수 제한 및 실패 기록,
     업로드 파일 형식·용량 제한, 접근권한 검증과 감사 로그를 적용하였고,
     개인정보처리방침 게시와 문의 시 수집·이용 동의 절차도 마련해 두었습니다.
   - 연구 참여자 자료는 이름·연락처 없이 식별코드·성별·연령만 가명 처리하여 보관합니다.

[개요]
 - 웹사이트명 : Trauma Stress Lab (적십자간호대학 정신건강간호연구실)
 - 도메인 : psynr.cau.ac.kr (기존 도메인, 연결 대상 변경)
 - 용도 : 연구실 소개, 연구성과 공개, 연구용 모바일 앱 개인정보처리방침 게시,
          연구자 전용 자료 포털
 - 서버 : 외부 클라우드(Render) 자체 운영, 교내 호스팅 미사용
```

## 4. 회신 이후 교수님이 하실 일

신청서 접수가 필요하다는 회신이면, 종합정보시스템 > 행정 > 정보통신처 > 신청서 관리 >
도메인 신청에서 **추가 → 사용자 정보 → 웹사이트명·도메인명 입력 → 취약점 점검표 첨부 →
개인정보처리시스템 점검표 첨부 → 개인정보 수집 동의 → 저장 → 승인요청** 순서로 진행.
기재값은 [`cau-domain-application.md`](./cau-domain-application.md) 3장 표를 그대로 옮기면 된다.

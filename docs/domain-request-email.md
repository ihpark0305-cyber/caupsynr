도메인·웹호스팅 신청의 **서비스 대상이 "교원, 직원"**(매뉴얼 3p)이라, 종합정보시스템
신청서와 정보통신처 문의 모두 **교수님 계정·교수님 메일**로 진행해야 한다.
아래 두 가지를 교수님께 부탁드리면 된다.

```

연구실 홈페이지를 새로 만들어 학교 도메인(tsl.cau.ac.kr)에 연결하려고 준비 중입니다.
도메인 신청은 교원·직원 계정만 가능해서, 두 가지만 부탁드리려고 합니다.

1) 점검표 양식 내려받아 전달 부탁드립니다
   - 위치: 종합정보시스템 > 행정 > 정보통신처 > 신청서 관리 > 도메인 신청
           화면 하단의 "의무 이행사항 안내"
   - 필요한 양식 두 가지
     · 홈페이지 취약점 심층점검 점검표
     · 개인정보 처리시스템 안전조치 관리실태 점검표
   - 양식만 주시면 제가 내용을 채워서 정리해 드리겠습니다.
     (홈페이지 보안 설정과 개인정보처리방침은 이미 반영해 두었습니다)

2) 정보통신처에 문의 메일 발송 부탁드립니다
   - 홈페이지가 외부 서버에서 운영되어 고정 IP가 없는데 신청서에는 IP를 적게 되어 있어,
     연결 방식을 먼저 확인받아야 합니다.
   - 아래 본문을 그대로 보내주시면 됩니다.
   - 받는 곳: 정보통신처 정보인프라팀

회신이 오면 신청서에 적을 내용까지 정리해서 드리겠습니다.
감사합니다.

## 3. 정보통신처에 보낼 메일 초안

> **받는 사람**: 정보통신처 정보인프라팀 (담당자 주소 확인 후 기재)
> **제목**: [도메인 신청 문의] tsl.cau.ac.kr 신규 발급 및 외부 호스팅 연결 방식 확인 요청 — 적십자간호대학 정신건강간호연구실

```
안녕하십니까.
중앙대학교 적십자간호대학 정신건강간호연구실(Trauma Stress Lab) 최윤정 교수입니다.

연구실 홈페이지 운영을 위해 도메인 tsl.cau.ac.kr 발급을 신청하고자 합니다.
종합정보시스템에 신청서를 올리기 전, 아래 세 가지를 먼저 확인 부탁드립니다.

1. 외부 호스팅 연결 방식 (CNAME 가능 여부)
   - 연구실 홈페이지는 Python/Flask로 개발되어 교내 웹호스팅(ASP·PHP)에서는
     운영이 어려워, 현재 외부 클라우드(Render)에서 운영 중입니다.
     현재 주소: https://caupsynr.onrender.com
   - 해당 서비스는 고정 IP를 제공하지 않고 호스트명 기준 연결(CNAME)을 사용합니다.
     tsl.cau.ac.kr 을 caupsynr.onrender.com 으로 CNAME 등록이 가능한지 확인 부탁드립니다.
   - 참고로 기존 psynr.cau.ac.kr 도 외부 서비스(Wix)로 CNAME 되어 있는 상태입니다.
   - CNAME 등록이 어렵다면 현재 IP(216.24.57.7 / 216.24.57.15)로 A 레코드 등록이
     가능한지, 이후 IP가 변경될 경우의 절차는 어떻게 되는지 함께 안내 부탁드립니다.

2. 기존 psynr.cau.ac.kr 정리
   - 과거 Wix로 제작한 연구실 홈페이지가 종료되어, 현재 psynr.cau.ac.kr 접속 시
     404가 반환됩니다.
   - 종료된 외부 서비스를 가리키는 레코드가 남아 있으면 서브도메인 탈취 위험이 있어,
     해당 레코드 삭제 또는 신규 도메인으로의 연결 변경을 함께 요청드립니다.

3. 첨부 점검표 확인
   - 홈페이지 취약점 심층점검 점검표를 작성해 첨부할 예정입니다.
   - 연구자 전용 로그인 기능이 있어(공개 회원가입은 없습니다)
     개인정보 처리시스템 안전조치 관리실태 점검표도 함께 첨부하려 합니다.
     대상 여부가 맞는지 확인 부탁드립니다.
   - 현재 사이트에는 HTTPS 전용 리다이렉트, HSTS 및 CSP 등 보안 헤더, CSRF 토큰 검증,
     비밀번호 해시 저장(PBKDF2-SHA256), 로그인 시도 횟수 제한 및 실패 기록,
     업로드 파일 형식·용량 제한, 접근권한 검증과 감사 로그를 적용해 두었습니다.
   - 연구 참여자 자료는 이름·연락처 없이 식별코드·성별·연령만 가명 처리하여 보관합니다.

[신청 개요]
 - 웹사이트명 : Trauma Stress Lab (적십자간호대학 정신건강간호연구실)
 - 신청 도메인 : tsl.cau.ac.kr
 - 용도 : 연구실 소개, 연구성과 공개, 연구용 모바일 앱 개인정보처리방침 게시,
          연구자 전용 자료 포털
 - 서버 : 외부 클라우드(Render) 자체 운영, 교내 호스팅 미사용
 - 담당 : 최윤정 교수 (yunjungchoi@cau.ac.kr, 02-820-6907 / 연구실 02-820-5986)

확인해 주시면 안내해 주신 방식에 맞추어 종합정보시스템에 신청서를 제출하겠습니다.
감사합니다.

## 4. 회신 이후 교수님이 하실 일

종합정보시스템 > 행정 > 정보통신처 > 신청서 관리 > 도메인 신청에서
**추가 → 사용자 정보 → 웹사이트명·도메인명 입력 → 취약점 점검표 첨부 →
개인정보처리시스템 점검표 첨부 → 개인정보 수집 동의 → 저장 → 승인요청** 순서로 진행.
기재값은 [`cau-domain-application.md`](./cau-domain-application.md) 3장 표를 그대로 옮기면 된다.

점검표 2종은 신청서 하단 "의무 이행사항 안내" 링크에서 양식과 작성 가이드를 받아
작성한다. 작성에 필요한 코드 근거는 같은 문서 5장에 정리돼 있다.
